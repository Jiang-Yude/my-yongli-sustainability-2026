# 官網產生器修改說明（給本機最新版 _build/build.py）

GitHub 上的 v7（最後 commit 2026-10-19，BASE_URL 還是 3481rctsi.vercel.app）比線上版舊，
所以這份說明不直接改 repo，請在本機最新版照著改，改完跑 build.py 與 check.py。

## 1. 網址統一不帶 .html（最重要）

線上 Cloudflare 會把 `/members.html` 308 轉到 `/members`。canonical、hreflang、og:url、sitemap、JSON-LD 都要改成轉址後的網址。

在 `url_of()` 改成：

```python
def url_of(lang, tree_rel):
    path = ("en/" if lang == "en" else "") + tree_rel
    if path.endswith("index.html"):
        path = path[:-len("index.html")]      # index.html → 資料夾網址（首頁 = BASE_URL + "/"）
    elif path.endswith(".html"):
        path = path[:-len(".html")]           # members.html → members
    return BASE_URL + "/" + path
```

其他寫死 `.html` 網址的地方一併檢查：llms.txt、site-index.json、agent.html 內文的絕對網址。
站內相對連結（href="members.html"）可以不改，伺服器會轉；有空再改成不帶副檔名，少一次轉址。

## 2. sitemap 加 lastmod

`write_sitemap()` 每個 `<url>` 加一行，日期用該頁 JSON-LD 的 dateModified（或檔案修改日）：

```python
f"    <lastmod>{date_str}</lastmod>\n"
```
